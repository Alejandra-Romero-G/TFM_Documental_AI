# Sistema Inteligente Multimodal para la Recuperación Semántica y el Análisis Automatizado de Documentos, Imágenes y Vídeos mediante IA Generativa y Bases Vectoriales

## Descripción

Este proyecto corresponde al Trabajo Fin de Máster en Big Data, Data Science e Inteligencia Artificial.

El objetivo es desarrollar una aplicación multimodal capaz de analizar, indexar y consultar información contenida en diferentes tipos de archivos utilizando técnicas de Inteligencia Artificial Generativa y Recuperación Aumentada por Generación (RAG).

La plataforma permitirá trabajar con distintos formatos de información, como documentos, imágenes y vídeos, ofreciendo una única interfaz desde la que el usuario podrá realizar consultas en lenguaje natural.

Entre sus principales funcionalidades se encuentran:

* Carga de documentos PDF, DOCX y TXT.
* Indexación semántica mediante embeddings.
* Búsqueda inteligente basada en significado.
* Comparación de documentos.
* Consulta mediante un asistente conversacional (RAG).
* Análisis de imágenes utilizando modelos multimodales.
* Análisis de vídeos mediante extracción de fotogramas.
* Localización visual de objetos o elementos relevantes en imágenes y vídeos.

## Tecnologías

* Python 3.11
* Streamlit
* Sentence Transformers
* ChromaDB
* LangChain
* CLIP
* YOLOv8
* OpenCV
* Docker

## Estado del proyecto

- Proyecto en desarrollo.

Actualmente se está implementando la infraestructura base para la carga de archivos, generación de embeddings y almacenamiento en una base de datos vectorial.

## Ejecución

1. Clonar el repositorio.
2. Crear un entorno virtual.
3. Instalar las dependencias mediante `requirements.txt`.
4. Ejecutar la aplicación con Streamlit.

## Objetivo

Desarrollar un prototipo funcional capaz de procesar información multimodal y responder preguntas en lenguaje natural utilizando modelos de Inteligencia Artificial y bases de datos vectoriales.
